# Responsive Design Notes

Prepared by: Naif Alenizi

## Goal
Document key responsive behavior checks for the EquipShare frontend.

## Layout Checks
- Verify navbar remains usable on smaller screens
- Verify cards stack correctly on mobile
- Verify dashboard sections do not overflow horizontally
- Verify admin tables remain readable on tablet widths

## Screen Sizes
- Mobile: 320px to 480px
- Tablet: 768px to 1024px
- Desktop: 1280px and above

## UI Notes
- Maintain readable spacing between cards
- Keep action buttons easy to tap on touch devices
- Avoid text overflow in listing cards and dashboard panels
