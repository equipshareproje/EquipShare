# UI Testing Checklist

Prepared by: Naif Alenizi

## Marketplace
- Verify marketplace page loads correctly
- Verify category filter updates visible listings
- Verify price filter updates visible listings
- Verify equipment cards show image, title, price, and rating
- Verify clicking a card opens listing details

## Booking Flow
- Verify user can select rental dates
- Verify booking summary updates correctly
- Verify total cost is displayed clearly
- Verify booking button is visible and clickable

## Dashboard
- Verify renter dashboard shows booking status
- Verify lender dashboard shows pending requests
- Verify earnings section displays summary data

## Admin
- Verify admin dashboard opens successfully
- Verify verification tab loads pending users
- Verify dispute tab loads dispute items
- Verify moderation tab displays flagged listings

## General UI
- Verify navigation works between pages
- Verify layout looks correct on mobile and desktop
- Verify buttons, forms, and cards use consistent styling
